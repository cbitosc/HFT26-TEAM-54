The pattern is too literal. (1) It only accepts single spaces between fields; the spec allows one or
more spaces or tabs, so edge_2 fails. Use [ \t]+ between DATE, TIME and [LEVEL]. (2) It requires
"[LEVEL]" with no inner whitespace; the spec allows optional spaces/tabs inside the brackets
(edge_4). Use \[[ \t]*(\w+)[ \t]*\]. (3) It never checks ranges, so hour 24 is accepted (edge_5).
Validate month 01-12, day 01-31, hour 00-23, minute and second 00-59. (4) It requires a space and
then a message after "]", so a line ending at "[INFO]" returns None instead of message "" (edge_7).
Make the message part (.*) follow the bracket directly and strip it. Use fullmatch on the stripped
line.
